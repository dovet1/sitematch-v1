# GapFinder Screenshots

This directory contains screenshots used on the GapFinder landing page.

## Required Screenshots

Based on the screenshots you provided, please save them to this directory with the following names:

1. **hero-interface.png** - Full GapFinder interface showing the map with 56 locations
   - Used in: Hero section (right side)
   - Source: Your full interface screenshot

2. **locations-sidebar.png** - Matching Locations sidebar showing 56 locations with population data
   - Used in: Product Showcase Card 1 ("Filter & Find Markets")
   - Source: Your locations list screenshot

3. **area-comparison.png** - Area Comparison modal showing categories and brand counts
   - Used in: Product Showcase Card 2 ("Analyze Brand Gaps")
   - Source: Your comparison modal screenshot

4. **missing-brands.png** - Missing Brands panel showing Asda with 3 types
   - Used in: Product Showcase Card 3 ("Understand Context")
   - Source: Your missing brands panel screenshot

5. **map-markers.png** - Satellite map with numbered location markers
   - Used in: Video Demo Section
   - Source: Your map view screenshot

6. **nearby-brands.png** (optional) - Nearby Brands list with travel times
   - Not currently used but available for future enhancements
   - Source: Your nearby brands screenshot

## Image Optimization

For best performance, optimize images:
- Format: WebP (with PNG fallback)
- Max width: 1200px for hero, 600px for cards
- Compress to reduce file size while maintaining quality

## Fallback

All images have a fallback to `/map-screenshot.png` if not found, so the page will still work without these specific images.
