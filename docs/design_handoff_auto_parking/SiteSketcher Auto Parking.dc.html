Automatic parking layouts in SiteSketcher

One interaction direction: the existing Parking tool gains a method choice. Manual is unchanged and stays the default. Auto layout reuses the same left panel, map and inspector, needs only a boundary and an access point, and reads existing polygons and CAD overlays as exclusions automatically.
