Auto layout, step by step

The Parking tool's Auto layout mode. The panel fills itself in as you go — draw a boundary, drop an access point, create layouts, then compare and drag things around until it's right. Any polygon inside the boundary is treated as an obstacle automatically; there's no separate step for it. The compare screen (04) is live — click the options to redraw the map.

RULEEditing the plot with the Select tool (outside Auto mode) never re-solves the layout silently. It flags the object out of date — amber dot in the list, bays at 50% clipped to the new boundary, and a Regenerate prompt — so a reviewed layout is never rearranged behind the user's back. (Inside Auto compare, by contrast, the same drag re-fits live.)
